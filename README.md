# TorqueDesk-Microservices
TorqueDesk Microservices é uma API RESTful desenvolvida com Spring Boot e Java 21 para gerenciar operações de oficinas mecânicas. Implementada utilizando arquitetura de microsserviços, oferece autenticação JWT, gestão de clientes, veículos, ordens de serviço e estoque, com serviços independentes, comunicação distribuída e suporte a multi-tenancy.
